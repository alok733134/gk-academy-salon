# GK Academy Showcase

A premium, modern web application showcase built with **React**, **TypeScript**, **Vite**, **TailwindCSS**, and **TanStack Start**. Fully optimized, fully responsive, and production-ready.

---

## 🚀 Getting Started

Follow these simple steps to set up and run the application locally:

### 1. Installation

First, install the project dependencies:

```bash
npm install
```

### 2. Run the Development Server

Start the interactive development server:

```bash
npm start
```

_Note: You can also use `npm run dev`._

The app will start running on **[http://localhost:8080](http://localhost:8080)**.

---

## 🛠️ Scripts & Commands

Below is a list of all available commands you can run:

| Command           | Action                                                                                  |
| :---------------- | :-------------------------------------------------------------------------------------- |
| `npm install`     | Installs all required packages and dependencies                                         |
| `npm start`       | Launches the local Vite development server on port `8080` (with hot module replacement) |
| `npm run dev`     | Alias for starting the development server                                               |
| `npm run build`   | Compiles a production-ready build for the client and Cloudflare server environments     |
| `npm run preview` | Runs a local preview of the production-compiled build                                   |
| `npm run lint`    | Runs ESLint and checks for any code style or syntax issues                              |
| `npm run format`  | Runs Prettier to automatically format all files to matching code standards              |

## 🏗️ Technology Stack

This application is built with state-of-the-art modern frontend technologies:

- **Framework Engine:** [TanStack Start](https://tanstack.com/router/v1/docs/start/overview) (modern SSR + hydration, file-based routing, and React Query integration)
- **Frontend Library:** [React 19](https://react.dev)
- **Bundler & Build Tool:** [Vite 7](https://vite.dev)
- **Styling System:** [TailwindCSS 4](https://tailwindcss.com) with bespoke custom configurations for optimal look & feel
- **Design System & Components:** Radix UI primitives & custom-styled premium elements (Accordion, Carousel, Charts, Forms, Dialogs)
- **Serverless Platform Ready:** Integrated with Cloudflare Pages via `@cloudflare/vite-plugin` and custom serverless entries
